# Torra Lenta

Site de uma cafeteria fictícia, feito primeiro para celular, em um único arquivo (`index.html`, HTML + CSS + JS puro).

- Elementos aparecem e somem suavemente ao rolar, nos dois sentidos.
- Cabeçalho some ao descer e volta ao subir; barra de progresso no topo.
- Navegação fixa embaixo no celular, cardápio em abas, tema claro e escuro automáticos.
- Respeita a opção "reduzir movimento" do sistema.

Publicado com GitHub Pages (branch `main`, pasta raiz).
